## Как продолжать

1. Прочитать `CLAUDE.md`, `docs/spec/00-rules.md`, этот файл, спецификацию текущего этапа.
2. Работать в ветке этапа, коммитить и пушить часто: незапушенная работа пропадает вместе с контейнером.
3. После каждого шага обновлять раздел «Сейчас» здесь (что сделано, что дальше, номер PR).
4. Merge в `main` только при зелёном CI. Владелец заранее разрешил сливать зелёные PR этапов.
