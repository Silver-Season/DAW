# 04. Экспорт WAV, AIFF, FLAC, MP3

## Цель

Выгрузить трек в файл, который можно послать, залить на стриминг или отдать на сведение. Экспорт работает быстрее реального времени, даёт посэмплово тот же звук, что и воспроизведение, умеет стемы и нормализацию по громкости.

В конце пользователь может: нажать `Cmd+Shift+R`, выбрать MP3 320 или WAV 24 бит, нормализацию −14 LUFS, получить файл, который звучит ровно как в DAW, и стемы каждой дорожки отдельно. А ещё прослушать любую старую версию проекта, не закрывая текущую.

## Границы

Входит: офлайн-рендер, окно экспорта, форматы WAV / AIFF / FLAC / MP3, битность и частота с ресемплингом, дизеринг, хвост реверба, стемы, нормализация по пику и по LUFS, отчёт о громкости, экспорт MIDI-клипа в `.mid`, прослушивание версий.

Не входит: экспорт видео, загрузка на сервисы, Ogg/Opus (позже, если попросят), экспорт в реальном времени через внешнее оборудование.

## Задача 4.1. Офлайн-рендер

- `engine/OfflineRenderer`: создаёт **отдельный** движок поверх копии модели (не трогая играющий), со своими экземплярами плагинов: состояние каждого устройства копируется через `getStateInformation` / `setStateInformation`. Пользователь может продолжать работать во время экспорта.
- Плагины получают `setNonRealtime (true)`, размер блока 1024, частоту проекта. `AudioPlayHead` сообщает `isPlaying = true`, позицию и темп, как при воспроизведении.
- Рендер идёт на фоновом потоке (`juce::Thread`), прогресс — атомик, интерфейс показывает окно с полосой, оставшимся временем и кнопкой «Отмена». Отмена удаляет недописанный файл.
- Диапазон: «Вся песня» (от 1.1.1 до конца последнего клипа), «Петля» или «Выделение» в Arrangement. Если Arrangement пуст, окно пишет «Аранжировка пуста. Запишите выступление из Session View в Arrangement (этап 3) и повторите экспорт» и кнопка недоступна.
- **Хвост**: после конца диапазона рендер продолжается, пока пик выхода ниже −90 dBFS в течение 1 секунды подряд, но не дольше 10 секунд. Переключатель «Добавлять хвост» (по умолчанию вкл).
- **Совпадение с воспроизведением**: при одинаковой частоте и детерминированных устройствах (Prisma) офлайн-рендер посэмплово совпадает с рендером через `FakeDevice` в реальном режиме. Это тест.
- Компенсация задержки плагинов (06) учитывается: первые `latency` сэмплов выхода отбрасываются, чтобы файл начинался ровно в 1.1.1.
- Метроном и предпрослушивание браузера в экспорт не попадают.

## Задача 4.2. Окно экспорта

Открывается `Cmd+Shift+R` (команда из 01 становится активной). Поля и значения по умолчанию:

| Поле | Варианты | По умолчанию |
|---|---|---|
| Что | Мастер · Все дорожки отдельно (стемы) · Выбранные дорожки | Мастер |
| Диапазон | Вся песня · Петля · Выделение | Вся песня |
| Формат | WAV · AIFF · FLAC · MP3 | WAV |
| Частота | 44,1 · 48 · 88,2 · 96 кГц | частота проекта |
| Битность (WAV/AIFF) | 16 · 24 · 32 float | 24 |
| Битность (FLAC) | 16 · 24 | 24 |
| MP3 | CBR 128 / 192 / 256 / 320 кбит/с, VBR V0 / V2 | CBR 320 |
| Дизеринг | Нет · TPDF · TPDF с формой шума | TPDF при 16 бит, иначе нет |
| Нормализация | Нет · По пику (−0,1 / −1 dBFS) · По громкости LUFS | Нет |
| Цель LUFS | −14 (Spotify, YouTube) · −16 (Apple Music) · −9 (клуб) · своё | −14 |
| Хвост | вкл / выкл | вкл |
| Куда | папка, по умолчанию `<проект>/Exports/` | |
| Имя | шаблон `{project} {date}` / для стемов `{project} - {track}` | |

- Запоминается последний выбор в проекте (`PROJECT/EXPORT` узел).
- Под настройками строка: «≈ 3:42, 37 МБ».
- После экспорта окно показывает итог: длительность, пик (dBTP), интегральная громкость (LUFS), диапазон громкости (LRA), кнопки «Показать в Finder» и «Прослушать» (играет файл через предпрослушивание браузера).
- Если без нормализации пик выше 0 dBFS, итог предупреждает: «Пик +1,8 dBFS: в файле будет клиппинг. Включите нормализацию или лимитер на мастере».

## Задача 4.3. Форматы

- WAV, AIFF, FLAC — средствами JUCE (`WavAudioFormat`, `AiffAudioFormat`, `FlacAudioFormat`). В WAV пишутся метаданные BWF: имя проекта, дата, темп в `bext`/`acid` чанке, чтобы другие DAW подхватили темп.
- **MP3** — библиотека **LAME 3.100** (LGPL 2, совместима с AGPLv3 при статической линковке с открытым кодом приложения).
  - Исходники `lame-3.100.tar.gz` с официального сайта (SourceForge), положить в `third_party/lame/` с файлом `SOURCE.md` (URL, версия, SHA-256 архива, лицензия). Проверить SHA-256 по официальному источнику, а не по памяти.
  - Написать `third_party/lame/CMakeLists.txt`, который собирает только `libmp3lame` (файлы из `libmp3lame/` и `libmp3lame/vector/` без фронтенда и без `mpglib`), с минимальным `config.h` (`HAVE_STDINT_H`, `STDC_HEADERS`, `HAVE_ERRNO_H`, `HAVE_FCNTL_H`, `HAVE_LIMITS_H`, `TAKEHIRO_IEEE754_HACK` выключен для переносимости, `HAVE_XMMINTRIN_H` только на x86_64).
  - Обёртка `app/Source/engine/Mp3Writer` с API как у `AudioFormatWriter`: `lame_init`, `lame_set_in_samplerate`, `lame_set_num_channels 2`, `lame_set_brate`/`lame_set_VBR`, `lame_set_quality 2`, `lame_init_params`, `lame_encode_buffer_ieee_float`, `lame_encode_flush`, затем `lame_mp3_tags_fid` для заголовка Xing/LAME (точная длина и gapless). ID3v2: название, исполнитель (из настроек проекта), темп.
  - Частоты MP3: 44,1 и 48 кГц (выше — ресемплинг до 48).
- **Ресемплинг** при частоте экспорта ≠ частоте проекта: рендер всегда идёт на частоте проекта, затем высококачественный ресемплер. В `core/include/daw/dsp/Resampler.h` — полифазный windowed-sinc (окно Кайзера, β = 9, 64 отвода на фазу, 256 фаз), подавление алиасов ≥ 100 дБ. Тест: синус 1 кГц 48 → 44,1 кГц, искажения < −100 дБ.
- **Дизеринг** при уменьшении битности: TPDF (сумма двух равномерных шумов ±1 LSB), и вариант с формой шума (фильтр ошибки 9-го порядка по Lipshitz или простой E-weighted 5-го порядка). Генератор шума с фиксированным зерном, чтобы экспорт был воспроизводим.

## Задача 4.4. Нормализация и измерение громкости

- `core/include/daw/dsp/Loudness.h`: измеритель по **ITU-R BS.1770-4 / EBU R128**:
  - K-взвешивание: два биквада (high shelf +4 дБ на ~1681 Гц и high-pass ~38 Гц) с коэффициентами, пересчитанными для любой частоты (формулы из BS.1770, а не таблица на 48 кГц).
  - Блоки 400 мс с перекрытием 75 %, абсолютный порог −70 LUFS, относительный −10 LU.
  - LRA: блоки 3 с, перекрытие 2/3, порог −20 LU, 10-й и 95-й перцентили.
  - True peak: 4-кратная передискретизация (полифазный FIR из ресемплера) и максимум модуля.
- Нормализация по LUFS требует двух проходов: первый рендер во временный 32-бит float файл с измерением, затем усиление и запись в итоговый формат. Если после усиления true peak выше −1 dBTP, применяется только то усиление, которое даёт −1 dBTP, и итог сообщает: «Достигнуто −15,2 LUFS вместо −14: ограничено пиком. Поставьте лимитер на мастер».
- Нормализация по пику — тоже два прохода (или один с временным файлом).

## Задача 4.5. Стемы

- «Все дорожки отдельно»: каждая дорожка рендерится в свой файл. Звук дорожки — после её фейдера и панорамы, без мастер-цепочки. Возвратные дорожки (06) — отдельными файлами. Плюс файл мастера, если стоит галочка «И мастер тоже».
- Для скорости стемы рендерятся за один проход: офлайн-движок пишет выход каждой дорожки в свой файл параллельно с мастером.
- Дорожки с mute по умолчанию пропускаются (галочка «Включая выключенные»).
- Нормализация для стемов: одно общее усиление для всех (чтобы баланс сохранился), рассчитанное по мастеру.

## Задача 4.6. Экспорт MIDI

- Правая кнопка по MIDI-клипу (сессия или шкала) → «Экспорт MIDI-клипа…» → `.mid` (тип 0, 960 PPQ, темп и размер проекта, ноты, контроллеры).

## Задача 4.7. Прослушать версию

- В списке версий (01, 1.7) кнопка «Прослушать» у каждой версии. Версия рендерится офлайн-движком во временный файл (кэш в `History/previews/vNNNN.flac`, удаляется при прореживании версий), пока идёт рендер — индикатор. Затем файл играет через предпрослушивание с позиции курсора текущего проекта, синхронно с ним: кнопка «А / Б» переключает на лету между текущим проектом и версией в одной и той же позиции.
- Пока прослушивается версия, транспорт текущего проекта играет, но его выход заглушён, чтобы позиция совпадала.

## Тесты

1. **Совпадение.** Демо-проект на Prisma: офлайн-рендер 8 тактов равен рендеру через `FakeDevice` посэмплово (максимальная разница 0).
2. **Хвост.** Нота с релизом 2 с в конце песни: файл длиннее диапазона на ≥ 2 с и ≤ 10 с, последние 1 с тише −90 dBFS.
3. **Форматы.** WAV 16/24/32f, AIFF, FLAC читаются обратно JUCE с той же длиной и (для 32f) теми же сэмплами. MP3 декодируется обратно (`juce::MP3AudioFormat` при `JUCE_USE_MP3AUDIOFORMAT=1` в тестовой сборке, на macOS также `CoreAudioFormat`), длина совпадает ± 1 кадр благодаря тегу LAME.
4. **Ресемплер** (core): синус 1 кГц 48 → 44,1 и обратно, THD+N < −100 дБ; синус 21 кГц 96 → 44,1 подавлен ≥ 100 дБ.
5. **LUFS** (core): эталонные сигналы EBU Tech 3341 (синус 1 кГц −23 dBFS стерео даёт −23,0 ± 0,1 LUFS; сгенерировать сигналы в тесте), true peak синуса на четверти частоты дискретизации с фазой 45° даёт +3 дБ над сэмпл-пиком ± 0,1.
6. **Нормализация.** После нормализации до −14 LUFS измерение файла даёт −14 ± 0,2, true peak ≤ −1 dBTP; при ограничении пиком сообщение содержит фактическое значение.
7. **Стемы.** Сумма стемов (без мастер-цепочки) равна мастеру с выключенной мастер-цепочкой ± 1e-6.
8. **Дизеринг.** 16-битный экспорт тишины с TPDF даёт шум ~ −96 dBFS RMS, без дизеринга тишина остаётся нулём.
9. **Отмена.** Отмена на половине удаляет файл.

## Готово, когда

- [ ] `Cmd+Shift+R` экспортирует мастер в WAV, AIFF, FLAC и MP3, файлы открываются в Музыке / QuickTime на Mac.
- [ ] Звук файла совпадает с воспроизведением (тест 1), хвост ревера не обрезан.
- [ ] Нормализация −14 LUFS даёт −14 ± 0,2, итог показывает пик, LUFS, LRA.
- [ ] Стемы всех дорожек выгружаются одним проходом.
- [ ] Экспорт быстрее реального времени минимум в 5 раз на демо-проекте (цифра в отчёте).
- [ ] MIDI-клип экспортируется в `.mid` и открывается в другой программе.
- [ ] Любую версию из истории можно прослушать и сравнить «А / Б» с текущей.
- [ ] LAME лежит в `third_party/lame` с `SOURCE.md` и лицензией, README перечисляет сторонние компоненты.
- [ ] Все тесты зелёные, CI зелёный, README обновлён.
